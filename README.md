# A Timeless Birthday — Dedicated to Cheky Check2 Gangmei ✨

> A bespoke, luxury editorial birthday tribute and cinematic memory monograph celebrating **Cheky Check2 Gangmei** on her **24th birthday**.

---

## 🌿 Highlights

- **8 Authentic Video Memories:** Complete preservation of all original video recordings from her life, automatically playing as you scroll into view.
- **Original Soundtrack:** Background music featuring *"The Kac-Ties — Happy Birthday"*, with smart audio ducking and a floating controller.
- **Surprise Opening:** Monograph slipcase cover with smooth animated entrance.
- **Editorial Design System:** Rich Forest Green (`#183B32`), Warm Cream (`#FAF8F5`), Warm Beige (`#D8C7A5`), and Cormorant Garamond typography.
- **Screening Room:** Documentary cinema player with 2.35:1 letterbox mode, chapter navigation, and auto-advance.
- **The Letter:** Digital handwritten letter on archival ivory parchment with dynamic typing animation.
- **Interactive Celebration:** Birthday wish module with custom celebratory confetti.

---

## 🛠️ Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite 5
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Confetti:** Canvas Confetti

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/YaoMingNegga/24Checky.git
cd 24Checky

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
